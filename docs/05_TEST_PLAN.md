status: skeleton  
updated: 2026-09-16

---

## 原则

- 先失败测试或规格再实现（行为变更）。  
- 测公共行为；不复制生产逻辑到期望值。  
- 信息泄露测试安排在核心阶段，不推迟到联机完成后。  
- 「编译通过/页面能开」≠ 玩法完成。  

## 核心用例清单（目标）

1. 牌组构成、发牌与传牌不重复、不丢牌  
2. 同阶段编号顺序、跳过、同人多牌、死亡后处理  
3. 骗徒、反应牌、Mastermind 及关键组合  
4. 身份交换后的知识权限与历史查看  
5. 阵营比较、平局、浪人、奖励、整局胜利  
6. 非法目标、越权、重复指令、过期指令  
7. 多房间隔离；公共消息与视图不泄暗信息  
8. 4 人、奇数人数、11 人  
9. 多浏览器会话完成至少一局 e2e  
10. 断线/超时/forceAdvance 行为  

## 阶段对应

| 阶段 | 测试重点 |
|---|---|
| 2 | 状态机骨架、Spy 链路、可见性泄露、非法指令 |
| 3 | 全牌种、4/11 人、反应链 |
| 4 | 协议幂等、房间隔离、集成 + Playwright 主路径 |
| 5 | 断线、超时、移动端人工验收 |

## 命令

```powershell
npm run typecheck
npm test
npm run test:e2e   # 阶段 4 后启用
npm run build
```
